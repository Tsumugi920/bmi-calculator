# bmi-calculator · BMI 计算器

纯静态单页应用：**无构建步骤、无依赖、无后端**，只有 4 个文件，双击即可使用。
所有数据保存在浏览器 `localStorage` 中，不上传任何服务器。

## 功能

- **BMI 计算**：输入身高（cm）与体重（kg），实时显示 BMI、类别（偏瘦 / 正常 / 超重 / 肥胖，采用中国成人标准 18.5 / 24 / 28），以及该身高对应的**健康体重区间**。
- **历史记录**：保存每次测量（同一天重复保存会更新该日记录），以表格展示，可单条删除。
- **历史曲线**：原生 SVG 绘制，可在「BMI 曲线 / 体重曲线」间切换；BMI 模式带类别色带与图例，体重模式叠加目标参考线；数据点悬停可查看详情。
- **目标体重**：设定目标后，以最早一条记录为起点自动计算进度百分比与剩余差值，达成时显示祝贺。
- **JSON 导入导出**：一键导出全部数据（含目标体重）为 JSON 文件；导入时校验数据合法性，确认后覆盖现有数据。
- **内置示例数据**：首次打开自动写入 5 条示例记录（身高 172 cm，体重 78.6 → 73.2 kg 的减重轨迹）和一条目标（68 kg），方便立即体验；清空后可在控制台执行 `localStorage.clear()` 再刷新恢复。

## 快速开始

方式一：直接用浏览器打开 `index.html`。

方式二（推荐，体验与线上一致）：

```bash
cd bmi-calculator
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 数据格式

存储键：`bmi-calculator-data-v1`（仅本机浏览器可见）。导出的 JSON 示例：

```json
{
  "app": "bmi-calculator",
  "version": 1,
  "exportedAt": "2026-10-25T08:00:00.000Z",
  "target": { "weight": 68 },
  "records": [
    { "id": "sample-0", "date": "2026-06-01", "height": 172, "weight": 78.6 }
  ]
}
```

导入时兼容该完整格式，也兼容纯记录数组（`[{date, height, weight}, ...]`）；
身高需在 40–260 cm、体重需在 10–400 kg 之间，非法条目会被自动过滤。

## BMI 判定标准（中国成人）

| BMI (kg/m²) | 类别 |
| ----------- | ---- |
| < 18.5      | 偏瘦 |
| 18.5 – 23.9 | 正常 |
| 24 – 27.9   | 超重 |
| ≥ 28        | 肥胖 |

健康体重区间按 BMI 18.5–24 换算：`体重 = BMI × 身高²(m²)`。

## 兼容性

Chrome / Edge / Firefox / Safari 等现代浏览器（使用了 ES2017+ 与 `color-mix` 之外的常规 CSS，无需联网）。换浏览器或清除浏览器数据会导致本地记录丢失，重要数据请定期「导出 JSON」备份。
